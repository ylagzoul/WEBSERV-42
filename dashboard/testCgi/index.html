🛠️ CGI Sandbox Suite

Execute targeted CGI functionality tests in Python and PHP environments.

📝 Test 1: Standard Payload (POST)

Goal: Validate key-value parsing of standard body parameters.

Sends structured textual fields to verify parameters are read, sanitized, and matched to their keys.

🎥 Test 2: File & Video Multipart Upload

Goal: Verify chunk-reading and file upload parsing (multipart/form-data).

Transmits binary video files, documents, or images to test raw request body buffer reading capabilities.

⏳ Test 3: Simulate 504 Gateway Timeout

Goal: Verify proxy limits and timeout configurations.

Instructs the backend execution process to freeze for 6 seconds. If your webserver's gateway timeout limit (Nginx, Apache, or IIS) is configured below 6 seconds, this triggers a 504 Gateway Timeout.

💥 Test 4: Simulate 502 Bad Gateway

Goal: Observe server response when CGI returns unparseable or corrupt data.

Causes the CGI process to return faulty header streams (missing the colon divider or valid HTTP parameters) triggering an immediate 502 Bad Gateway handler in upstream servers.
