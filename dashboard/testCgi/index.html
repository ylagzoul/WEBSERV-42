🛠️ CGI Sandbox Suite

Execute targeted CGI functionality tests in Python and PHP environments.

📝 Test 1: Standard Payload (POST)

Goal: Validate key-value parsing of standard body parameters.

Sends structured textual fields to verify parameters are read, sanitized, and matched to their keys.

🎥 Test 2: File & Video Multipart Upload

Goal: Verify chunk-reading and file upload parsing (multipart/form-data).

Transmits binary video files, documents, or images to test raw request body buffer reading capabilities.

⏳ Dedicated 504 Gateway Timeout Tests

Goal: Test isolated 10-second delays to verify proxy timeouts.

These buttons call standalone, lightweight scripts that simply sleep for 10 seconds to test your web server's threshold limits.

💥 Dedicated 502 Bad Gateway Tests

Goal: Verify proxy error handling when a CGI process crashes.

These buttons load dedicated, lightweight scripts that return malformed header streams or exit abruptly to force a 502 Bad Gateway response from your web server.
