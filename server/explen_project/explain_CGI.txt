

# CGI: means Common Gateway Interface.
    ~Quetions:
        + What is CGI:

            - It is a way for a web server to talk with a program (like a script written in C, Python, PHP…).

            - Simple idea
                * When a browser sends a request:
                    ** If it’s a normal file → server sends it directly (HTML, CSS…)
                    ** If it’s a CGI request → server runs a program, then sends the result back

            - Example:
                * User opens:
                    > http://example.com/cgi-bin/hello.py

            - What happens:
                * Server sees it's a CGI script
                * Server runs hello.py
                * The script generates output (HTML text)
                * Server sends that output to the browser


        + What we use CGI for

            - CGI is used to create dynamic content:
                * Forms (login, register)
                * Search pages
                * File upload
                * Generate HTML dynamically
                * Connect to database
                * Important note

            - old style. Today we use better things like:
                * FastCGI
                * Node.js
                * frameworks (Django, Laravel…)

            - Because CGI:
                * starts a new process for each request ❌ (slow)
                * uses more resources ❌
                * In your case (webserv project)

            - You use CGI to:
                * execute scripts (like .py, .php)
                * send request data (headers, body) to the script
                * read script output and return it as HTTP response


        + What is a script?

            - A script is a small program written in a simple language that runs directly (no big compilation step like C++).
                * Simple idea
                    ** A script is just a file like:
                        > print("Hello")
                    ** You run it directly:
                        > python3 file.py

            - In CGI (very important for you)
                * A CGI script is a program that:
                    ** reads data from the server (request)
                    ** does some work
                    ** prints a response (HTML)
                * Example CGI script:
                    **
                        #!/usr/bin/python3
                        print("Content-Type: text/html")
                        print()
                        print("<h1>Hello Youssef</h1>")
                    **
                    ** This script:
                        *** does not send HTTP headers like your server
                        *** only prints content → server sends it back to client
                        
            - Why do we need scripts?
                * We need scripts to make dynamic websites.
                * Without scripts:
                    ** server only sends static files (HTML, CSS)
                * With scripts:
                    * you can create dynamic things like:
                    ** login system
                    ** forms
                    ** database queries
                    ** upload files
