////////////////   send    ///////////////////////

🧠 لماذا send() يمكن أن يرجع EWOULDBLOCK؟

لأنك تستعمل non-blocking socket.

🔵 ماذا يحدث داخل النظام؟

عندك شيء اسمه:
👉 send buffer (buffer ديال الإرسال)

الحالة العادية:
send(fd, data, size, 0);

👉 إذا كان buffer فيه مساحة:

يتم الإرسال ✔️
يرجع عدد bytes
🚨 الحالة المهمة:

إذا كان buffer ممتلئ:

send(...) → -1
errno == EWOULDBLOCK

👉 المعنى:

لا يمكن الإرسال الآن
حاول لاحقًا

💡 لماذا يمتلئ buffer؟
client بطيء في القراءة
الشبكة بطيئة
أنت ترسلdata كبيرة



////////////////   recv    ///////////////////////

🔵 مثال:
int bytes = recv(fd, buffer, 1024, 0);

إذا لا توجد بيانات:

bytes == -1
errno == EWOULDBLOCK
💡 المعنى ببساطة

👉 مثل EAGAIN تمامًا:

لا يوجد data الآن
لا تنتظر
حاول لاحقًا
